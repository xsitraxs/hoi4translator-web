# 🌍 HoI4 Localization Tool (React Web Edition)

**Batch-translate Hearts of Iron IV mod localization without breaking Paradox formatting.**

Web-версия инструмента пакетного перевода локализации модов Hearts of Iron IV, переписанная на React + TypeScript с сохранением полной бизнес-логики, строгого парсера формата Paradox и валидатора маркеров.

---

## ✨ Возможности

* **Движки перевода:** Google Translate, DeepL (с поддержкой API-ключа), MyMemory и автономный тестовый движок JavaSim.
* **Цепочка фолбэка:** `DeepL → Google → MyMemory`. Если платный движок недоступен или исчерпал квоту, строка мягко переходит к следующему движку с фиксацией в отчёте.
* **Защита маркеров Paradox:**
  * Переменные и форматтеры: `$VALUE$`, `$$`, `[GetTag]`, `[GetPlayerTag]`, `[?value|%G0]`
  * Цветовые коды: `§R`, `§W`, `§!`, градиенты `§0`–`§9`, динамические цвета `§[...]` и литеральные `§§`
  * Иконки: `£money`, `£army_experience|1`, `£GFX_army|1`
  * Спецсимволы и экранирование: `\n`, `\t`, `\"`
* **Глоссарий терминов:** загрузка файлов TSV / CSV / JSON или ввод терминов прямо в интерфейсе. Термины маскируются перед отправкой в переводчик и возвращаются уже переведёнными.
* **Переиспользование ванили:** подключение файлов оригинальной игры для автоматического использования официальных переводов без траты квот.
* **Предпросмотр перед записью:** редактируемая таблица до 1000 строк с валидацией плейсхолдеров перед сохранением.
* **Восстановление битых строк:**
  * *Не записывать файл* (строгий режим).
  * *Заменить битую строку оригиналом* (файл сохраняется, проблемная строка остаётся на языке оригинала и помечается в отчёте).
* **Умный кэш:** локальное хранилище браузера сохраняет переводы и сверяет контрольные суммы SHA-256 для выявления изменений в исходниках.
* **Экспорт результатов:** пакетное скачивание переведённых файлов в `.zip` архиве с сохранением структуры каталогов и кодировкой UTF-8 BOM (`\uFEFF`), а также отчётов в форматах JSON и CSV.

## 🛠 Запуск в режиме разработки

```bash
npm install
npm run dev
```

Приложение доступно по адресу `http://localhost:3000`.

## 📦 Сборка для production

```bash
npm run build
```
